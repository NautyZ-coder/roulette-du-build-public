# La Roulette du Build

Ouvrir `index.html` dans un navigateur. C'est tout.

Un métier, un problème, un outil, une contrainte : la roulette tire, Brice construit, le reel montre.

- Espace ou bouton **Tirer au sort** → 4 rouleaux s'arrêtent l'un après l'autre
- **Garder** → verrouille un rouleau pour le prochain tirage
- **Copier le brief** → texte prêt pour la caption ; **Lien** → URL rejouable (`#s=seed`)
- **Format 9:16** → cadrage reel pour le screen recording

Modifier les listes : tableau `REELS` dans le `<script>` de `index.html`.
