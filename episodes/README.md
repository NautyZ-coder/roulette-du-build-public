# Épisodes

Un dossier par épisode : `NN-<seed>-<slug>/`

- `BRIEF.md` — le tirage exact (métier, problème, contrainte, temps, seed). Jamais choisi à la main.
- le code du mini-projet (un fichier si possible)
- `SCRIPT-REEL.md` — les deux reels de l'épisode (mardi = tirage + plan, jeudi = build + résultat)

L'**outil n'est pas tiré** : la roulette donne le problème, c'est toi qui choisis comment le résoudre.
Ce choix est un morceau de contenu à part entière — il se raconte dans le reel du mardi.

## Gabarit `BRIEF.md`

```markdown
# Épisode NN — <slug>

- Seed : `xxxxx`
- Métier : …
- Problème : …
- Contrainte : …
- Temps : … min
- Outil choisi (par moi) : … — parce que …

## Ce que je livre
…

## Ce que je ne fais pas
…
```

## Gabarit `SCRIPT-REEL.md`

```markdown
## Reel 1 — mardi : le tirage + le plan
- Hook (0-4 s) : la roulette qui tourne, les 4 rouleaux tombent.
- Phrase rituelle : « La roulette a parlé. <métier>, <problème>, <contrainte>. J'ai <X> minutes. »
- Le raisonnement : ce que j'élimine, l'outil que je choisis et pourquoi.
- Fin : « à ton avis, je pars sur quoi ? »
- CTA : commente <MOT-CLÉ> et je te dis comment j'attaquerais ton cas — pour toi ou pour tes clients, actuels ou futurs.

## Reel 2 — jeudi : le build + le résultat
- Hook (0-3 s) : le problème métier, concret et chiffré.
- Le build : screen recording réel, voix off réenregistrée. Les erreurs restent.
- Le résultat : la démo qui marche (ou ce qui n'a pas marché dans le temps imparti).
- CTA : identique au reel 1.
```
